Solve Chamados

Sistema Corporativo de Gestão de Suporte

Sobre o Projeto

O Solve Chamados é uma solução enterprise desenvolvida para otimizar o fluxo de atendimento técnico. O sistema foi construído pensando em robustez, utilizando uma arquitetura baseada em domínios (DDD) para garantir que a lógica de negócio seja independente de ferramentas externas.

Principais Funcionalidades

  • Gerenciamento de chamados com priorização inteligente
  • Geração de relatórios em PDF (Padrão A4) com gráficos de performance
  • Dashboard administrativo para monitoramento de KPIs em tempo real
  • Sistema de autenticação JWT com níveis de acesso (Admin, Técnico, Cliente)
  • Dockerização completa para deploy ágil em qualquer ambiente

Tecnologias Utilizadas

React.js Node.js TypeScript PostgreSQL Docker DDD Architecture
