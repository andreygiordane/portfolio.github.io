VeloDesk

Acesso Remoto de Alta Performance

Sobre o Projeto

O VeloDesk é uma ferramenta de suporte remoto projetada para oferecer a menor latência possível. Utilizando tecnologias WebRTC, o sistema permite que técnicos acessem computadores de clientes diretamente pelo navegador ou aplicativo desktop, sem a necessidade de configurações complexas de rede.

Principais Funcionalidades

  • Transmissão de vídeo em tempo real via WebRTC (P2P)
  • Controle remoto total de mouse e teclado
  • Túnel de conexão criptografado e seguro
  • Versão Desktop construída com Electron
  • Baixo consumo de CPU e memória

Tecnologias Utilizadas

WebRTC Python Electron Socket.io React
